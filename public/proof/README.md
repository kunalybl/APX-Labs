# Proof assets

Drop your **real** proof here — it loads into the site automatically. No code changes needed.

| Folder | What goes here | Renders in |
|--------|----------------|------------|
| `/public/proof` | Positive email replies, booked-meeting screenshots, campaign stat crops (images) | Evidence Wall |
| `/public/screenshots` | Live campaign dashboards, sequence performance (images) | Case Studies showcase |
| `/public/videos` | Client video testimonials (`.mp4` / `.webm`) | Testimonials |

**Naming → captions:** filenames become captions automatically.
`positive-reply-solar.png` → "Positive Reply Solar". Use numbers to order: `01-...`, `02-...`.

**Video posters (optional):** place a `.jpg` next to a video with the same name
(`owner-solar.mp4` + `owner-solar.jpg`) and it's used as the thumbnail.

Supported images: `.png .jpg .jpeg .webp .avif .gif` · videos: `.mp4 .webm .mov .m4v`.

Until you add files, elegant "verified proof" placeholders show in their place —
nothing ever renders broken.
